# LinguaFlow – Language Translator

## About the Project
LinguaFlow is a web-based language translation tool that helps users translate text from one language to another through a simple and user-friendly interface.

## Features
- Text translation
- Multiple language options
- Source and target language selection
- Swap languages
- Copy translated text
- Text-to-speech functionality
- Responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript
- Translation API
- Web Speech API

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html in a web browser.
